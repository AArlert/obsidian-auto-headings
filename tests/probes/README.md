## 怎么跑

需要一个能在 Obsidian 里执行任意 JS 的通道，且**只用于测试库**（不要在日常使用的库里跑），例如一个只装在测试库里、
监视某个文件并执行其内容的开发用小插件，或 Obsidian CLI 的 `eval`（适合短脚本）。把脚本内容交给它执行，读回返回值。

窗口要在前台（脚本会先 `focus()`）；输入法拼字靠 CDP 的 `Input.imeSetComposition` 模拟，脚本结束会
`detach` 调试器、删掉临时文件夹 `探针-AH时序`、恢复 VC 原来的启用状态。

> **跑之前先确认跑的是这一版**：把新构建拷进库之后，Obsidian 里加载的还是**拷之前**的那份代码——文件新
> 不等于内存里新。要禁用再启用本插件（或重启 Obsidian），再用一行 `typeof` 自查（例如「不选就记住」是
> `!!app.workspace.editorSuggest.suggests.find(x=>x.plugin===app.plugins.plugins["auto-headings"])?.dismissed`）。
> 2026-10-24 就因为漏了这一步，首轮探针全是旧规则的结果。

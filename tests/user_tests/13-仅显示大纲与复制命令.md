# 仅显示模式的大纲编号 + 两条复制命令（testplan V40–V44、R1–R6）

准备：一条「仅显示」的路径规则（例如 `测试/` → 默认模板，模式选「仅显示」），并打开 Obsidian 自带的大纲面板
（命令「大纲：显示大纲」）。

## 一、大纲面板显示编号（V40–V44）

1. 在 `测试/` 下新建 `大纲.md`，粘贴下面的内容。
2. 看右侧大纲面板。

预期：

- 大纲里每个标题前的编号与编辑器（实时预览）里逐条一致；编辑器里不编号的标题（默认模板下的 H1）大纲里也不编号。
- 大纲顶部的搜索框输入「背景」过滤：只剩这一条，编号不变；清空后全部恢复。
- 折叠「概述」再展开，编号不丢；标题多到要滚动时，滚下去的条目也有编号。
- 在编辑器最前面插入一行 `## 新增`：一两秒后大纲刷新，所有编号顺延。
- 在大纲里把「方法」拖到「概述」前面：编号随之重排。
- 设置 → 全局设置 → 关掉「在大纲中显示编号」：大纲里的编号立即消失；打开后立即恢复。
- 打开一篇**写入模式**、已编号的笔记：大纲里只有文件本来的编号，没有第二层。
- 把大纲面板固定（钉住）在 `大纲.md` 上，再切到别的笔记：大纲仍按 `大纲.md` 显示编号。

```md
# 文档标题

## 概述
概述正文。

### 背景
背景正文。

### 动机
动机正文。

## 方法
#### 跳级的四级标题

## 结论
结论正文。
```

## 二、复制编号大纲（R1–R3）

在 `大纲.md` 里执行命令「复制编号大纲」，粘贴到任意地方（记事本即可）。

预期：

- 每个标题一行，编号与编辑器里看到的一致，最浅的一级不缩进，每深一级多两个空格。
- 切到阅读视图再执行一次，照样能用。
- 对一篇没有标题的笔记执行：只提示没有标题，剪贴板不变。
- 对一篇写入模式、已编号的笔记执行：内容就是标题上的文字（编号 + 标题），粘贴出来没有看不见的怪字符。

## 三、复制当前小节链接（R4–R6）

1. 在 `大纲.md` 里把光标放在「动机正文。」这一行，执行「复制当前小节链接」。
2. 新建一篇 `引用.md`，粘贴。

预期：

- 粘贴出的是一条指向「动机」的链接（默认形如 `[[大纲#动机|动机]]`；若在设置里关了 Wiki 链接，则是 Markdown 链接），点击能跳到「动机」。
- 光标放在「文档标题」上面（第一个标题之前）时，命令面板里找不到这条命令。
- 回到 `大纲.md`，把「动机」改成「研究动机」：`引用.md` 里的链接锚点跟着更新，点击仍能跳转。
- 对写入模式的已编号笔记做同样的事：链接能跳转；之后在它前面插入标题让编号变化，链接照样跟着更新。

# Auto Headings（自动标题编号）

[English](https://github.com/AArlert/obsidian-auto-headings/blob/master/README.md) | **简体中文**

给 Obsidian 标题自动编号，跟得上你的每一次修改：增删、挪动章节，编号自动理顺；改了标题名，指向它的链接也不会断。

## 为什么选 Auto Headings

-   **可以完全不改文件。** 默认只在 Obsidian 里显示编号，笔记内容一个字都不动。需要编号跟着文件走（GitHub、Publish、外部编辑器）时，再按文件夹切到「写入文件」。
-   **编号自己会改对。** 在长笔记中间插一节，后面的编号就全部顺延好了。
-   **链接不会断。** 改了标题的名字，指向它的 `[[笔记#标题]]` 链接会一起更新。
-   **想要什么样式都行。** `1.1.1`、`第一章`、`一、`、`①`、`I.`、`a)`……不同文件夹还能各用一套。
-   **不该编号的自动跳过。** 「目录」「附录」「参考文献」不编号，也不占用序号。
-   **哪里都能用。** 桌面端、移动端都支持，界面中英双语。

## 快速上手

1. 在 **设置 → 第三方插件** 里安装 **Auto Headings** 并启用。
2. 打开一篇笔记开始写，`##` 及更深的标题前面会显示 `1`、`1.1`、`1.1.1`……文件本身不会被改动。
3. 就这样。想换样式、或者想把编号写进文件，再打开 **设置 → Auto Headings**。

## 功能

### 只显示，或者写进文件

每条路径规则都可以单独选模式：

-   **仅显示**（新安装的默认）：编号只出现在 Obsidian 的实时预览、阅读视图和导出的 PDF 里，笔记文件一个字都不改。源码模式照原样显示原文。
-   **写入文件**：编号作为真正的文字写进笔记，在 GitHub、Obsidian Publish、外部编辑器里也看得到。

两种模式用同一套模板，编号完全一样。随时可以切换，切换时插件会先告诉你有多少篇笔记受影响，再按你的选择清掉或写入编号。从旧版本升级的库保持原来的「写入文件」。

### 全自动编号

仅显示模式下，编号随着你打字实时更新。写入模式下，你停下打字后才悄悄重排编号，一次 `Ctrl/Cmd+Z` 就能撤销。两种模式都只处理你正在编辑的那篇笔记，也从不改动你的标题层级（`#`、`##`、`###`）。

### 链接跟着标题走

```
## 2 快速开始      →   ## 2 上手指南
[[指南#快速开始]]  →   [[指南#上手指南]]
```

改了标题文字，库里指向它的链接会同时更新，Wikilink 和 Markdown 链接都算在内。不需要的话随时可以关掉。

### 每类笔记一套模板

每一级标题都能单独选序号样式、前缀和后缀，边改边实时预览。再按文件夹分配模板：`论文/` 用学术编号，`书稿/` 用章节编号，`日记/` 干脆不编号。

### 让某些标题不编号

内置中英文常用词表，「目录」「附录」「参考文献」这类标题默认就不编号。词表可以自己增删，也可以把整个章节连同下面的子标题一起排除。

### 边打字边链接标题

在正文里打出库中某个标题的名字，会弹出建议，按 `Tab` 就变成指向它的链接。

### 接管已有笔记

手打的或从别处导入的编号，一条命令就能清掉，之后交给插件自动编号。

## 命令

| 命令                     | 作用                                                                  |
| ------------------------ | --------------------------------------------------------------------- |
| 立即重新编号             | 马上给当前笔记重排编号                                                |
| 清除当前文件编号         | 去掉当前笔记的全部编号                                                |
| 清理非本插件的标题编号   | 只去掉手打或导入的编号                                                |
| 清除本文件残留的插件编号 | 仅显示模式下，去掉文件里以前写入的旧编号                              |
| 切换全局自动编号         | 为整个库开 / 关自动编号                                               |
| 复制编号大纲             | 把当前笔记的标题复制成带编号的缩进大纲（写入 / 仅显示两种模式都可用） |
| 复制当前小节链接         | 复制指向光标所在小节的链接（写入 / 仅显示两种模式都可用）             |

## 常见问题

**会改我没在编辑的笔记吗？**
只有两种情况会：一是你改了一个被其他笔记链接的标题（链接同步，可以关掉）；二是你在设置里确认执行了批量操作，比如切换模式时选择清除或写入编号。

**会往笔记里加隐藏的东西吗？**
仅显示模式下什么都不加。写入模式下只加一样：每个编号带一个不可见的标记字符，插件靠它区分自己写的编号和你的正文。它不会显示出来，从 Obsidian 复制内容出去时也会被自动去掉。它对搜索、Dataview、Pandoc 有什么影响，[使用指南](https://github.com/AArlert/obsidian-auto-headings/blob/master/doc/user-guide.zh.md#工作原理以及一件你应该知道的事)里写得很清楚。

**占资源吗？**
很少。插件不联网，不收集任何数据。启用时会在本地读一遍全库的标题，用于「边打字边链接标题」（不需要可以在设置里关掉）；之后编号只处理你正在编辑的那篇笔记。内存用量有上限：标题索引最多 5 万条，剪贴板缓存约 2 MB。

**以后不想用了怎么办？**
仅显示模式本来就没改过你的文件，直接卸载即可。用过写入模式的话，在 **设置 → 敏感操作** 里可以清除全库编号，也可以保留编号、让它们变成普通文字，两种都作用于整个库。

**我之前用的是 Number Headings。**
先禁用它，再启用本插件，然后对旧笔记跑一次「清理非本插件的标题编号」。按文件夹排除编号、跳过注释里的标题这两项也都支持。

**能和别的自动编号插件一起用吗？**
不能。两个编号插件会抢着改同一批标题，请只启用其中一个。

## 安装

-   **社区插件市场（推荐）：** **设置 → 第三方插件 → 浏览**，搜索「Auto Headings」，安装并启用。
-   **手动安装：** 从[最新 Release](https://github.com/AArlert/obsidian-auto-headings/releases/latest) 下载 `main.js`、`manifest.json`、`styles.css`，放进 `<库>/.obsidian/plugins/auto-headings/`，然后重载 Obsidian。

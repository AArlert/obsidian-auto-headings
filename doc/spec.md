# obsidian-auto-headings

> 一款 Obsidian 插件，两层价值（定位论证见 [附录 A](./spec/A-方向审查与否决理由.md) §A.1）：
> **① 改标题不断链**——`[[file#heading]]` 内部链接随标题改写自动同步，可独立于编号工作（1.0.8 起）；
> **② 全社区最强的标题自动编号**——完全自定义多模板、按路径配置、白名单豁免，编号直接写入正文（burn-in）。
> 界面中英双语（0.6.5 起，自动跟随 Obsidian / 可手动锁定）。

> **本文件是规格的顶层索引**：正文按节拆在 [`spec/`](./spec/) 目录，一节一文件，文件名 = `节号-短名.md`。
> 节号是稳定引用 ID：代码与测试注释里的「spec §3.22」即 `spec/3.22-*.md`。增删改节文件须同步本索引
> （`npm run docs` 双向校验）；本索引只放标题链接，不复述正文。

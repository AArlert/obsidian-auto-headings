# N. 起始编号数字 startIndex（M8 批次 1） — dev + user

> 模板级字段，默认 1。**仅首段**（`topLevel` 对应段）从该值起，更深层级仍从 1 起（设 0 得 `0.1.1`）。
> 实现为**渲染期偏移**（`buildPrefix`）：计数器内部恒为 1 起，0 仍是「跳级缺失」哨兵，剥离靠 WJ 边界与序号字形无关。
> **UVM 已纳入随机化**（0.7.13）：`setStartIndex` 激励（0/1/2/5）+ startIndex=0 / non-default 覆盖 bin，500×60 与 5000×80 全绿。

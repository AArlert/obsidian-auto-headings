# 3.13 设置面板多 TAB（M7）

> **1.2.2 视觉更新**（[Roadmap M15](./5-Roadmap.md#milestone-15--视觉风格更新122功能不变)，功能不变、只改呈现）
> 已全部落地，本节按 1.2.2 现状描述；逐项场景见 testplan L9 / L20 / L27–L45、J22–J24。

单页设置面板已溢出（testplan L 类多项手验困难、移动端更甚），0.7.11 重构为**四 TAB**，`SettingsTab.ts`
仅作壳（版本号 + TAB 栏 + 分发），各 TAB 内容拆到 `settings/tabs/`（每文件 <300 行可整读）：

设计决策：

- **危险操作靠 TAB 隔离**：旧「危险区域默认折叠」由独立 TAB（1.2.2 起「编号维护」）替代，不再与常用
  设置同屏；当前笔记的四条命令在此 TAB 补面板入口（对**当前活动文件**执行，设置面板打开时活动视图可能
  为 null——testplan TPL-refresh 同源，按 `getActiveFile()` 回退查找，无文件弹 Notice）。1.2.2 起去掉橙色
  警告横幅，改为「整个仓库」组标题旁一行警示；**红色只在最后一步**：页面上是红字普通按钮，确认框里输入
  确认词后才出现可点的红底按钮（防误触而非防恶意，确认词忽略大小写与首尾空白）。
- **清除全库期间临时压制自动编号**（`vaultClearInProgress` 内存标志 + 取消全部待处理防抖）：批量写回
  会触发已打开文件的 `editor-change`，不压制的话刚清掉的编号会被立刻编回去；完毕（含异常）恢复。
  **0.7.17 起清库前还会先持久关闭「全局自动编号」**（testplan H7）：清完却留着开关开，一编辑又被编
  回去——反直觉；清库 = 用户明确表态「现在不要编号」，故先关再清，需要时手动再开（双语 desc 与确认
  对话框已注明；frontmatter `true` 的文件不受全局开关约束，故清库期间的临时压制仍保留）。
- **TAB 图标化 + 窄屏滑动**（0.7.17，testplan L21/L22）：TAB 用 Obsidian 内置 lucide 图标
  （`setIcon`，SVG currentColor 黑白随主题；刻意不用 emoji——系统 emoji 字体固定彩色不吃 CSS）。
  未激活 = 仅图标（名称经 aria-label/title 提供），激活 = 图标 + 文字 + 主题强调色背景；
  TAB 栏 `overflow-x: auto` 自身横向滑动，窄屏绝不撑宽设置页。图标映射：全局设置 `settings`、
  路径模板 `folder-cog`、编号维护 `wrench`（1.2.2 前为 `alert-triangle`）、关于插件 `info`。
  **TAB 名一律四个字**（1.2.2 定），以后新增 TAB 也取四字名、中英双语。
- **弹窗标题用原生 `Modal.setTitle`**（1.2.2，L27）：不再 `createEl("h3")` 自绘——自绘标题吃主题的
  标题色，也不和关闭按钮同行。
- **模板编辑弹窗**（1.2.2，取代 0.7.17 的行内展开面板，testplan L35–L42）：卡片「编辑」打开宽弹窗
  （桌面约 1080px，手机全屏），标题区在原生 `titleEl` 里（小字「编辑模板」+ 模板名 + 铅笔就地改名）；内部
  两 TAB「格式 / 白名单（条数）」；改动**即时生效**（与旧面板一致），底部只有「完成」和一行影响说明（按每篇
  笔记实际解析出的规则计数，`templateView.ts` `summarizeTemplateUsage`）。格式页：上方「编号范围」「更多
  规则」两行；格式表「继承前级 + 继承级数」合成一列「上级编号」（不带 / 全部 / k 级，写回仍是两个字段）；
  未聚焦时空格显示为「␣」；范围外的级别整行一句灰字；预览列只一例；底部预览块用与编辑器同一编号引擎
  渲染当前笔记或示例，悬停表格行时同级高亮。白名单页顶部一行图例，命中 0 不显示角标。
  序号样式下拉标签为纯示例字形（「1, 2, 3」，L24）。
- **设置面板输入的 IME 感知**（0.7.17，testplan J8/L25）：拼音等组合输入期间（`isComposing`）
  文本输入框不提交、编辑器防抖到点顺延一个周期，`compositionend` 后再提交 / 写回——否则组合中间态
  （半截拼音）被逐键保存并编入标题。document 级 compositionstart/end 维护 `imeComposing` 标志。
- **默认模板显示名随语言**：存储名恒「默认」、文件名恒 `default.json`，仅 GUI 显示层按语言映射
  （「默认」/「Default」），路径规则引用与磁盘不变。
- **配套精简**：各设置说明**一行化**（中文 ≤ 32 字、英文 ≤ 90 字符，`i18n.test.ts` 守门；长解释下沉使用
  指南与本 spec）；路径规则表窄屏改两行布局（1.2.2 取代原横向滚动）。
- **预览优先于文字说明（设计原则）**：能用渲染示例说清楚的地方不写说明文字，示例已经暴露的信息不用
  文字复述——既有先例是 `previewLevel()` 的逐级示例与白名单编辑器的实时预览。仅当预览无法表达"为什么
  这样设计"（如 `ancestorNumeral` 这类概念性取舍）时才保留一句话说明。**已知缺口**：`skipFill`（跳级
  占位策略 fill/drop/none）目前只有文字描述、没有配对的渲染示例，是这条原则的第一个待补项，见
  Roadmap M9。
- 当前 TAB 是**面板存续期**的视图态（重开面板回到「全局设置」），不持久化；编辑弹窗里的白名单搜索 /
  排序、预览来源同理，只在弹窗存续期保持。

# 3.17 跳过区域：围栏与注释块（M12）

「插件不该介入的区域」由 `src/scan.ts` 的 `scanSkipRegions` 统一判定，两类：**围栏代码块**
（``` / ~~~，须同种符号、且闭合行反引号/波浪号数量 **≥** 开启行数量才算闭合，CommonMark 行为）
与**注释块**（`%%…%%` / `<!--…-->`，M12 新增）。区域内的 `#` 行一律**不视为标题**：不编号、
**不推进计数器**、不进 backlink 快照。

> 实现收敛：此前 `parser.ts` 与 `numbering.ts` 各维护一份同构的围栏状态机、且后者要反向从
> `./parser` 借 `FENCE_RE`。现统一到 `scan.ts`。UVM 参考模型（`tests/dev_tests/uvm/model.ts`）
> **刻意不复用**它——那是交叉验证用的独立第二实现，复用被测代码即丧失验证价值。

## 裁决表

围栏是**行级**的，注释是**字符级**的、可在同一行内开闭，故不能沿用「整行跳过」的写法。

| # | 规则 | 裁决与理由 |
|---|------|-----------|
| R1 | 注释可行内开闭 | 必须按字符位置判定，而非整行 |
| R2 | **行首定标题**：某行是标题 ⟺ 它第 0 列时不在注释内、不在围栏内、且本身不是围栏定界行 | 与 CommonMark「块结构由行首决定」一致 |
| R3 | `## 标题 %% 批注 %%` | **是标题**（`#` 未被遮蔽）；注释原文留在 `rawText`，编号写在其左侧 |
| R4 | `## 标题 <!--` | **本行仍是标题**；注释自该处开启，遮蔽**下方**各行直到 `-->` |
| R5 | 围栏优先：围栏内不扫描注释标记，注释状态冻结 | 反向（注释内的 ``` 会开启围栏）列为**已知限制**——失败方向是「多跳过 / 冻结」而非「误编号」，安全 |
| R6 | 行内代码 `` `<!--` `` 内的标记照常触发 | **已知限制，不处理**：正确处理需 CommonMark 级的反引号游程 tokenizer，与收益不成比例；同样是「冻结」方向的失败，可见且可恢复 |
| R7 | 未闭合注释延伸到 EOF | 与未闭合围栏对称。`renumberContent` 不剥已有前缀 ⇒ 是**冻结而非损坏**，补上闭合符即完全恢复 |
| R8 | 不嵌套：`<!-- <!-- -->` 首个 `-->` 即闭合 | HTML 语义 |
| R9 | 未开启时只扫开标记，已开启时只扫匹配当前风格的闭标记 | `%%` 的「开闭同符」是退化情形，无需特判；与围栏机的 `fenceChar` 同形状 |
| R10 | 贪婪左到右：`%%%` = 开标记 + 残留 `%` | 静态用例钉死（testplan E26） |
| R11 | 围栏闭合行数量 < 开启行数量（如外层 4 根反引号包内层 3 根，嵌套写法） | **不闭合**，该行只是围栏内的普通内容、不算定界行；整块仍视为未闭合直至真正数量 ≥ 开启行的收尾行。CommonMark 规则；根治 issue #9（数量不足被误判闭合，导致内层 `#` 被当真标题，反向推进更深层计数器归零） |

## 区域内残留的分区域分治 ★

已编号的标题被**事后**包进注释块 / 围栏后，它的 WJ 前缀会留在区域里。`parseHeadings` 已不再返回该行，
不额外处理就会永远留着。两类区域**故意给不同待遇**（`cleanDemotedResidue` 的 `ResidueScope`）：

| 区域 | 自动重编号路径 | 显式清除命令 |
|------|--------------|-------------|
| 注释块 | **清掉** WJ 前缀 | 清掉 |
| 围栏代码块 | **原样冻结** | 清掉 |
| 正文（既有降级残留） | 现状不变 | 现状不变 |

理由：**注释块是隐藏散文**——里面的 WJ 残留在阅读视图根本不可见，用户肉眼永远找不到，留着毫无价值，
插件清掉自己留下的东西是安全的。**围栏代码块是字面内容**——日常编辑中绝不能改写，否则一段
「演示本插件 WJ 格式的代码块」会在敲字过程中被静默吃掉。

但**清除命令必须两类都清**：否则注释里那份不可见残留会挺过「清除全库编号」，直接违背
[2.7 标记契约](./2.7-标记字符契约.md)「永远可退出 / 精确剥净」的承诺。

判据一律用 **WJ 而非「看起来像编号」**：区域内只处理含 WJ 的行（标题形 `## ⁠1.2 ⁠标题` 与降级残留
`⁠一、⁠标题` 两种形态），无 WJ 的普通文本一个字符不动——契约明说「无 WJ 即插件从未染指」。
一行同时属于两类时（注释内开了围栏，见 R5）**以围栏为准**，取更保守的一侧。

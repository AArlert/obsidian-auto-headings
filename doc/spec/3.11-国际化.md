# 3.11 国际化（中英双语 M6；另有 8 种可缺省翻译）

设置面板、命令名与 Notice 提示**全部支持中英双语**，另提供繁體中文、日本語、Español、Français、Deutsch、Русский、한국어、Português do Brasil（`src/i18n/`）。

- **语言来源：** 设置面板顶部「语言」下拉——**自动（跟随 Obsidian）** + 十种语言：中文、繁體中文、日本語、
  Español、Français、Deutsch、Русский、한국어、Português do Brasil、English。默认「自动」；选项文字取各语言的
  自称（`LANG_SELF_NAMES`），不随界面语言变化。选定后面板立即用新语言重绘。
- **「自动」判定：** 读取 Obsidian 的界面语言（官方 API `getLanguage()`，1.8.0+；1.0.1 起弃用早期的
  `localStorage["language"]` 探测，商店审核要求），`_` 视同 `-`、不分大小写：`zh-TW` / `zh-HK` / `zh-MO` /
  `zh-Hant*` → 繁體中文；其余 `zh*` → 简体中文；`ja` / `es` / `fr` / `de` / `ru` / `ko` 语言码（含地区后缀，
  如 `es-419`）→ 对应语言；`pt*`（`pt` / `pt-BR` / `pt-PT`）→ Português do Brasil；其余一律英文；调用失败回退
  英文。`loadSettings` 对 `language` 做合法值校验（`isLang`），非法或缺失回退 `auto`。
- **文案结构：** `Messages` 接口列出全部界面字符串；`zh` / `en` 两套**完整实现且形状完全一致**（TS 保证
  不漏键，单测另校验键集合相同）。需插值的（防抖范围、清除计数、模板名等）以函数给出。
- **非完整语言与回落：** 其余八种（`zh-TW` / `ja` / `es` / `fr` / `de` / `ru` / `ko` / `pt-BR`）的类型是
  `Partial<Messages>`，取用时经 `withEnglishFallback`（`{...en, ...partial}`）合并——**缺的键回落英文**，
  社区可以只翻一部分就提 PR。繁中由简体逐条转换并按台湾用语校对（「設定 / 檔案 / 連結 / 外掛 / 預設 /
  範本」）；其余语言各自采用 Obsidian 官方界面里的叫法（如 heading / link / vault / plugin 的本地译名），
  **均无母语审校**。这八种语言目前都只缺省语言无关的 10 个键（语言自称、数字样式、纯格式化函数）；
  非 CJK 语言另缺 `numeralCjk`（与英文相同）。俄语的数量文案用 `pluralRu` 处理复数。
- **单测（`i18n-locales.test.ts`）：** auto 判定各分支、这八张表的键都是 `Messages` 的合法键且类型一致、
  缺省键只能是语言无关项、一行化上限（繁中 ≤ 32 字；日 / 韩 ≤ 56 字；西 / 法 / 德 / 葡 / 俄 ≤ 100 字符，
  超了改文案而非放宽）。
- **文档范围：** README / 使用指南仍只维护中英。
- **只译界面、不译数据：** 模板名「默认」、白名单词条、frontmatter 键名等属**用户数据 / 协议**，保持原样
  不翻译，避免破坏文件名映射与持久化。
- **命令名时机：** 命令在 `onload` 注册时取一次语言，故**改语言后命令名需重载插件才更新**（面板有提示）；
  Notice 在调用时取语言，**即时生效**。

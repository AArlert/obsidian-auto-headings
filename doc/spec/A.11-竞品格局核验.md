# A.11 竞品格局核验（2026-07-18，源码级实测）

> 起因：外部 AI（GPT）两轮给出竞品分析，市场数据可核实部分（下载量、版本数、更新时间）经
> `community-plugin-stats.json` 逐项核对**全部准确**；但"最危险对手是谁"的判断两轮各不相同、
> 且明显顺着对话者上一句话漂移，遂对四个主要竞品逐一拉源码本地实测，得到比转述可靠的结论。
> 下载量快照：number-headings-obsidian 86,725（停更 2023-10）；header-enhancer 10,604（活跃）；
> obsidian-title-serial-number-plugin 7,908（创建 2021-12，20 星）；auto-heading（gurjar1）871
> （近两月 34 个版本，增速最快）；auto-numbered-headings 333；本插件 107。

**核心发现：无标记（WJ 或等价标记）的编号插件，实测都会吞用户内容。** 这是本插件双哨兵方案
存在的最短论证，逐个复现如下（均为逐字复刻对方源码正则 + 本地跑得到的可复现结果，非转述）：

- **obsidian-title-serial-number-plugin**（720 行，仅 Set/Clear 两条手动命令，零自动触发，
  `editor.setValue()` 整文替换）：识别"旧序号"的正则含 `[A-Za-z]+`，无任何标记——
  `## Python 教程` → `## 1 教程`、`## Getting Started` → `## 1 Started`、`## 2024 总结` →
  `## 1 总结`，英文/数字开头的标题首词被永久吞掉，Set/Clear/超出层级范围三条路径均中招。
  与本文 testplan **E18**（`## 2024 总结` 首次编号后完整保留 `2024`）建模的场景完全对应。
- **header-enhancer**（4,100 行，Enter 键 + 命令触发，非防抖常驻）：空格分隔模式同样无标记，
  `## 2024 总结` → `## 1 总结`、`## 1.5 倍速播放` → `## 1 倍速播放`，纯数字开头标题被吞
  （英文标题因其正则要求数字打头而幸免，比 TSN 收敛但同病）。**其反链管理只在自身编号操作
  改写标题后触发**（`main.ts:582`/`707`，全仓无 `rename` 事件监听）——不管用户手动改名，
  本插件"改名不断链"仍是全场独家，此前两轮 GPT 分析均未查证这点、直接采信了其宣传。
- **auto-heading（gurjar1）**：本插件双哨兵方案鸣谢并升级的对象，用的是**单哨兵**（仅前缀首部
  一枚 WJ）。其 `manualNumberDetector.ts` 做了置信度分级 + 罗马数字误报词表 + ≥50% 多数投票的
  启发式收编，工程认真，但 catch-all 正则 `\d{1,4}` 的注释自称"限 1-4 位数字以避开 2024 这类
  年份"、实测**并未避开**——即便是同段位的工程对手，启发式仍有天花板，标记方案才有确定性。
  `manifest.json` 声明 `isDesktopOnly: true`——**它是本品类里唯一放弃移动端的插件**（2026-08-09
  复核五家 manifest：仅 gurjar1 为 `true`，header-enhancer / number-headings / title-serial-number /
  auto-numbered-headings 均为 `false`）。其 README 称 WJ 对 copy-paste "no effect"（不实，正是本插件
  O8 在修的问题）。

**可借鉴、不构成威胁重估的两点**（均已知竞品之外的新增，登记于 M12 候选，非本轮拍板）：

1. gurjar1 有"复制编号大纲到剪贴板"命令（`commandRegistry.ts:195`）与"复制当前小节链接"命令
   （`commandRegistry.ts:306`），均可低成本移植，且与本插件"改名不断链"的反链能力形成更完整
   的复制/分享闭环。
2. gurjar1 的样式检测 + 一致性投票逻辑（用于运行时收编既有编号，本插件不采用该用途）换个场景
   可用：《从 Number Headings 迁移》向导可借同样的检测思路自动识别用户既有编号样式、预选匹配
   模板，把迁移从"先读文档再配置"降到"一键确认"。

**结论**：不改变 A.0/A.1 的定位判断（链接不断链仍是核心叙事），但新增三个可对外验证的差异化
论点，供未来 README 竞品对比节或迁移向导取用——**均需附版本号、保持客观陈述可复现行为，不做
攻击性表述**：① 上表三条"吞用户内容"实测可复现，是 WJ 类方案存在必要性的最短证明；② 最活跃的
对手 gurjar1 桌面端限定，本插件移动端可用（**不可写成"唯一"或"独占"**——2026-08-09 复核：其余四家
manifest 均为 `isDesktopOnly: false`，此处原文曾误写为"活跃竞品中唯一移动端可用"，属会被当场证伪的
过度承诺，已订正）；③ Header Enhancer 的反链维护不覆盖用户改名，"改名不断链"仍是独家卖点。

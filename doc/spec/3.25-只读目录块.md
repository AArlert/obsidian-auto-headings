# 3.25 只读目录块 `ah-toc`（M17-B，未发版）

**定位**：用户在笔记里放一个围栏代码块，插件在阅读视图 / 实时预览 / 导出 PDF 里把它**渲染**成当前文件的目录。
**渲染本身只读**：不把目录文本写进文件；块内容是用户写的那几行，插件**唯一的写入**是用户拖滑块松手时改写
块内 `depth:` 一行（见「层级滑块」，边界见 [2.2](./2.2-非目标.md)）。存在的理由：仅显示模式
（[3.22](./3.22-虚拟编号模式.md)）的编号不在文件里，别的目录插件拿元数据缓存拼目录，拼出来没有编号；
自己渲染就能在目录里带上与编辑器一致的编号，写入模式 / 仅显示模式都对。

````markdown
```ah-toc
slider
```

```ah-toc
slider
levels: 2-3
depth: 3
```
````

## 插入

命令「插入目录」（命令名就这四个字；命令面板 + 编辑器右键菜单，需要编辑器焦点）在光标处插入一个**带 `slider` 的块**
（内容只有 `slider` 一行）；光标所在行非空时前后补换行，不把块粘进一行文字中间。手写块仍是显式 opt-in：
不写 `slider` 就没有滑块（与 1.x 早先行为一致）。

## 围栏名与参数

- **围栏名 `ah-toc`，不用 `toc`**：Automatic Table Of Contents 等插件注册了 `toc`，Obsidian 的代码块处理器按语言名
  登记，同名后注册的覆盖先注册的，谁赢取决于加载顺序——不和它们抢。
- 参数三个、都可省略、顺序无关：`slider`、`levels: A-B`、`depth: N`。`levels: A-B` 收录第 A 到第 B 级（`levels: 3`
  即只收第 3 级）；写不出合法范围（缺省、`abc`、`5-2`、超出 1–6）一律当作收录全部级别，不报错。`depth` 见下节。
  不设别的参数（产品原则：不加理解成本）。

## 渲染

- 数据：`metadataCache.getCache(sourcePath).headings`（级别 + 行号 + 原文）。**结构按相对级别栈式嵌套，缩进按级别对齐**：
  一个标题挂在它前面最近的更浅标题下（父子关系只看相对级别）；缩进以**收录的最浅级别为基准**，一个标题比「父级的
  下一级」多跳过几级，就多缩进几格——所以 H3 下直接出现的 H5，与别处 H4 下的 H5 **缩进一致、对齐**（用户 2026-10-28
  实测定）。**实现上目录平铺成一个列表**，每项带 CSS 变量 `--ah-toc-indent = 级别 − 最浅级别`，缩进 = 该值 × 1.5em（**每一级之间距离相等**），圆点自己画；不靠嵌套 `ul` 的内边距
  （嵌套的缩进是「祖先层数」，跳级的标题会比别处同级别的缩得少，对不齐——第一版就是这么错的）。文件里只有 H3–H5 时 H3 是顶层（不缩进），不会因为「没有 H1/H2」而空出两层；先出现更深的标题
  （文首是 H4、后面才有 H3）时，它按级别差缩进，随后的 H3 回到顶层。
- 编号：文件是仅显示文件时，取 `virtualNumberingFor(path, content)` 的结果，按标题**行号**对应、并核对级别，对不上 /
  该标题不编号（白名单、`<!-- skip -->`、超出层级范围）/ 带残留旧编号都不画——与大纲面板同一套「宁缺勿错」
  （[3.22](./3.22-虚拟编号模式.md)「内置大纲面板」）。编号用既有 `.ah-virtual-number` 样式的 span，不进文本，复制不带。
  写入模式文件编号本在标题文字里，直接显示（剥掉不可见的 WJ，不再叠一份）；读不到文件内容就退化成不带编号的目录。
- 文字：标题原文当**纯文本**显示（粗体、链接等行内标记不渲染，只剥 WJ）；不收录被 `levels` 排除的级别。没有标题就
  什么都不画（空块，不放提示文案）。
- 跳转：每项是 `a.internal-link`，点击走 `openLinkText(path#锚点, sourcePath, 修饰键新开)`，锚点用 `displayAnchor`
  （保留 WJ，写入模式的标题才解析得到，见 [3.12](./3.12-Backlink同步.md)）。同名标题的锚点歧义与手写
  `[[#标题]]` 一致（解析到第一个）。
- 更新：块登记成 `MarkdownRenderChild`；本文件 `metadataCache` 的 `changed` 事件、设置 / 模板 / 规则变化
  （`refreshVirtualViews`）时按当前内容原地重画，不整页重渲染。卸载插件时块恢复成普通代码块。

## 层级滑块（`slider`）与 `depth:`

块里写一行 `slider`（或 `slider: on` / `true` / `yes` / `1`；`off` / `false` 等当作没写）就带滑块，拖动选
「展开到第几级」。

- **默认隐藏**：滑块放在目录**上方、靠左**（避开实时预览里代码块右上角的 `</>` 按钮），**鼠标移到目录块上 / 键盘焦点
  进来时才淡入**，平时不可见；隐藏时仍占一行，显隐不会让目录跳动；没有悬停能力的设备（触屏）上常显，打印 / 导出
  PDF 时不出现。
- **取值 = `levels` 范围内文件里实际存在的级别**，滑块按「现存级别的序号」布置刻度：文件只有 H3–H5 就是 3 档
  （H3 / H4 / H5）；H3 + H5（没有 H4）就是 2 档，不会出现选了没效果的空档。范围内只剩一个级别时不显示滑块。
  默认停在最深一级（全部展开）。旁边用 `H3` 这样的小标签显示当前级别，不放需要翻译的文案。
- **拖动即时生效，松手才落盘**：拖动过程只重画列表、不重建滑块（否则丢焦点）；松手（`change`）时把选中的级别写进
  块内 `depth: N` 一行（已有就改、没有就追加在块末尾），下次打开 / 重启 / 换设备同步后仍停在这一级。
- **写入的安全边界**：只改这一个块、只动 `depth:` 这一行。写之前用 `getSectionInfo` 取块的行区间，并核对「开头是
  `ah-toc` 围栏、结尾是配对围栏、中间内容与渲染时拿到的一致」，任何一项不符（块被挪动 / 被编辑 / 取不到区间）
  就**放弃落盘、只保留本次内存里的选择**，绝不盲写；走 `vault.process` 原子改写，不碰文件其余部分。
- `depth:` 的语义是「最深收录到第几级」，取现存级别中 **不超过它** 的最大一级（`depth: 4` 而文件只有 H3、H5 时落在
  H3）；全都比它深时取最浅一级；写不出合法数字（`abc`、`9`、`0`）当作没写，停在最深。只有带 `slider` 的块才读它。
- 写文件是「用户拖滑块」这个明确动作的结果，不是后台行为；代价：Git / 同步工具里会看到这一行变更，阅读视图里
  的改动进不了撤销栈。想要固定显示深度、不想让文件被改，用 `levels:` 并去掉 `slider`。

## 实现

`src/virtual/tocBlock.ts`：纯函数 `parseTocLevels` / `parseTocSlider` / `parseTocDepth` / `selectableLevels` /
`buildTocTree` / `rewriteTocBlock` / `tocInsertText`（node 单测）+ 渲染器 `TocBlockRenderer`

# 3.25 只读目录块 `ah-toc`（M17-B，未发版）

**定位**：用户在笔记里手写一个围栏代码块，插件在阅读视图 / 实时预览 / 导出 PDF 里把它**渲染**成当前文件的目录。
**只读渲染，不写文件**：块内容永远是用户写的那几行，文件字节不变（边界见 [2.2](./2.2-非目标.md)）。存在的理由：
仅显示模式（[3.22](./3.22-虚拟编号模式.md)）的编号不在文件里，别的目录插件拿元数据缓存拼目录，拼出来没有编号；
自己渲染就能在目录里带上与编辑器一致的编号，写入模式 / 仅显示模式都对。

````markdown
```ah-toc
```

```ah-toc
levels: 2-3
```
````

## 围栏名与参数

- **围栏名 `ah-toc`，不用 `toc`**：Automatic Table Of Contents 等插件注册了 `toc`，Obsidian 的代码块处理器按语言名
  登记，同名后注册的覆盖先注册的，谁赢取决于加载顺序——不和它们抢。
- 参数只有一个、可省略：`levels: A-B`（收录第 A 到第 B 级，`levels: 3` 即只收第 3 级）。写不出合法范围（缺省、
  `abc`、`5-2`、超出 1–6）一律当作收录全部级别，不报错。不设别的参数（产品原则：不加理解成本）。

## 渲染

- 数据：`metadataCache.getCache(sourcePath).headings`（级别 + 行号 + 原文）。**按相对级别嵌套**：栈式构建，
  跳级（H1→H3）时 H3 直接挂在 H1 下，不补空层；先出现更深的标题（文首就是 H3）时它自己成一层根。
- 编号：文件是仅显示文件时，取 `virtualNumberingFor(path, content)` 的结果，按标题**行号**对应、并核对级别，对不上 /
  该标题不编号（白名单、`<!-- skip -->`、超出层级范围）/ 带残留旧编号都不画——与大纲面板同一套「宁缺勿错」
  （[3.22](./3.22-虚拟编号模式.md)「内置大纲面板」）。编号用既有 `.ah-virtual-number` 样式的 span，不进文本，复制不带。
  写入模式文件编号本在标题文字里，直接显示（剥掉不可见的 WJ，不再叠一份）；读不到文件内容就退化成不带编号的目录。
- 文字：标题原文当**纯文本**显示（粗体、链接等行内标记不渲染，只剥 WJ）；不收录被 `levels` 排除的级别。没有标题就
  什么都不画（空块，不放提示文案，免得动 10 种语言）。
- 跳转：每项是 `a.internal-link`，点击走 `openLinkText(path#锚点, sourcePath, 修饰键新开)`，锚点用 `displayAnchor`
  （保留 WJ，写入模式的标题才解析得到，见 [3.12](./3.12-Backlink同步.md)）。同名标题的锚点歧义与手写
  `[[#标题]]` 一致（解析到第一个）。
- 更新：块登记成 `MarkdownRenderChild`；本文件 `metadataCache` 的 `changed` 事件、设置 / 模板 / 规则变化
  （`refreshVirtualViews`）时按当前内容原地重画，不整页重渲染。卸载插件时块恢复成普通代码块。

## 实现

`src/virtual/tocBlock.ts`：纯函数 `parseTocLevels` / `buildTocTree`（node 单测）+ 渲染器 `TocBlockRenderer`
（`registerMarkdownCodeBlockProcessor`，main.ts 接入）。不写任何文件，不新增设置项。

# 1. 背景

Obsidian 社区呼声第一的痛点是**改标题断链**：`[[file#heading]]` 式内部链接在标题改名后即刻失效，官方无解，既有方案（Header Enhancer）还要求先启用其编号功能。本插件把「标题改名不断链」作为第一价值：拥有全社区最可靠的改名检测引擎（快照基线 + 按序配对），并自 1.0.8 起可完全独立于编号触发（CR-18；开关保守默认关，稳定后翻默认以兑现「装上即不断链」的零配置目标——定位倒转的论证见 [附录 A](./A-方向审查与否决理由.md) §A.1）。

在此之上是插件的第二层价值、也是历史起点：**标题自动编号**（面向写规格、论文、法律文书等需要编号进正文的场景）。手动维护编号极易出错——中间插入一节就要重编其后所有内容；本插件挂接编辑器事件，在可配置的防抖延迟后检测标题变化，把编号前缀直接写入文件（burn-in 哲学，编号是真文本而非渲染层装饰）。每一级标题的显示格式（中文数字、法律编号、字母列表等）完全可自定义，规则可按文件夹乃至单个文件分别配置；编号引发的标题改写同样自动同步内部链接。

# 2.7 标记字符契约（对下游的稳定承诺）

> 正文为英文（受众是下游插件开发者、脚本作者与外部工具用户），单一事实源在
> [`doc/marker-contract.md`](../marker-contract.md)，本节只放中文摘要，不复制细节。

契约承诺四件事（`1.x` 全程有效，未来变更须携带自动迁移 + 主版本号）：

1. **格式稳定**：标记字符恒为 U+2060 Word Joiner，双哨兵位置恒为「`#{1,6} ` 之后一枚 + 标题正文
   之前一枚」，两 WJ 之间（含）即插件属地；旧单哨兵格式（0.6.4–0.7.19）被继续识别。未编号标题
   **不以 WJ 起头**——行首无 WJ 即插件从未染指（标题中间可能有链接锚点带的 WJ，那是正文，见 2.5）。
2. **键名稳定**：frontmatter 开关键恒为 `obsidian-auto-headings`（用户数据协议，与 manifest id
   无关）。
3. **永远可退出**：身份活在字节里 → 卸载多年后仍可（重装 + 清除全库，或契约里给出的一行命令）
   把自家编号精确剥净。
4. **互操作配方**：契约内给出匹配归一（剥 WJ）、剥整前缀、shell 批处理、Pandoc Lua filter 四套
   下游代码片段，以及与其他 U+2060 插件**共存不受支持**的声明。

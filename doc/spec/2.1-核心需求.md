# 2.1 核心需求

| 编号 | 需求描述 |
|------|----------|
| CR-01 | 在可配置的防抖延迟（默认 300 ms）后检测标题变化，并将编号前缀写入当前活跃的 `.md` 文件 |
| CR-02 | 编号直接写入文件（而非仅注入渲染层） |
| CR-03 | 每个模板可配置**起始编号层级 `topLevel`**（默认 H2）：比它浅的标题完全不编号、且**不被改写**；它及更深的标题正常编号，并以它为序号第一段。默认 H2 即「H1 作标题/分节、不编号」 |
| CR-04 | **插件永不改写标题的 `#` 层级**（不对多个 H1 做任何降级/重排）。文件中可有任意多个 H1：低于 `topLevel` 的标题原样保留，但仍充当计数器**重置边界**（其后更深标题重新从 1 起）；需对个别标题（如某行标题）豁免编号时用白名单 |
| CR-05 | 命中白名单的标题不添加编号前缀，且**不占用计数器槽位**（计数器不累加、不跳号）。白名单支持**三种匹配方式**——**全部匹配**（修剪空格后完全相等）、**部分匹配**（标题包含该词）、**子树匹配**（命中标题及其下属所有子标题整体豁免）；当同一标题被多条目命中时按优先级 **全部 ＜ 部分 ＜ 子树** 取最强者。**例外（决策 D1，0.7.10）**：**子树**豁免块视为独立结构，块结束后计数器**整体重置**、其后编号重新开始（见 [3.7](./3.7-白名单系统.md)） |
| CR-06 | 白名单为**模板级**配置，随模板生效（路径专属模板覆盖全局默认模板）；所有配置**仅在插件设置 GUI 中管理**，不写入 frontmatter |
| CR-07 | 每个标题级别的显示格式由**模板**定义，模板完全可由用户自定义；每级可单独设置**继承前级**（默认开启，可关闭），关闭后该级不拼接父级序号，仅呈现本级序号 |
| CR-08 | 可定义多个具名模板；路径匹配规则将每个文件夹（或文件）映射到指定模板 |
| CR-09 | 插件内部使用纯阿拉伯数字计数器追踪各标题级别；显示格式（序号样式与间隔符）仅在写入文件时才应用 |
| CR-10 | 每次触发时对整个文件重新编号（而非仅修改编辑点附近的区域），确保全局一致性 |
| CR-11 | 提供**面板全局开关**与对应的 Obsidian **全局命令**，可整体启用/禁用自动编号 |
| CR-12 | 支持通过 frontmatter 键 `obsidian-auto-headings`（类型：Obsidian 复选框；值 `true`/`false`）对单个文件局部控制；非法值（含旧版 `ON`/`OFF` 文本、大小写不符者）忽略 |
| CR-13 | 界面**中英双语**（0.6.5 落地）：自动跟随 Obsidian 语言 / 可手动锁定，文案集中于 `src/i18n.ts`（见 [3.11](./3.11-国际化.md)） |
| CR-14 | 模板中每级标题可单独配置**继承前级**（布尔，默认开启）；关闭时该级不继承父级序号，编号前缀仅为「前缀 + 本级序号 + 标题间隔符」 |
| CR-14b | 继承前级开启时，还可单独配置**继承级数**（正整数或"全部"，默认全部）：限定最多往上拼几个祖先段，起点永不越过 `topLevel`。用于「H1 独立成章、H3 只带 H2 父级」这类中间态——此前只能靠调深 `topLevel` 绕，代价是连带取消浅层编号（1.0.22，社区 PR #7） |
| CR-15 | 提供侧栏大纲面板，实时展示当前文件的编号后标题树，支持按层级筛选、按文本/编号搜索并保留树形结构、点击跳转编辑器（M8a，规划中，见 [3.14](./3.14-侧栏大纲导航.md)） |
| CR-16 | 支持在大纲面板中拖放调整标题的层级与顺序，操作后一次性完成重新编号与 backlink 同步；支持在面板内直接编辑标题文本（M8b，规划中，见 [3.15](./3.15-拖放重排与结构编辑.md)） |
| CR-17 | 提供单文件内的目录生成能力：专属围栏代码块内自动生成、并随标题结构持续同步当前文件的目录，写入真实 Markdown 文本（而非渲染层展示）；更新联动编号引擎的防抖触发路径，且不得扰动用户当前光标/视图位置（M10，规划中，见 [3.16](./3.16-原生风格TOC-burn-in.md)） |
| CR-18 | Backlink 同步可独立于编号模板触发：即便某文件未命中任何编号模板（或全局自动编号关闭且该文件未 frontmatter 强制开启），只要标题文本被改写，仍应检测改名并同步引用链接，不以"编号引擎本次是否有写入"为前提（**1.0.8 落地为独立 opt-in 开关，1.0.9 并入 `updateBacklinks` 单开关全局生效**，见 [3.12](./3.12-Backlink同步.md)） |

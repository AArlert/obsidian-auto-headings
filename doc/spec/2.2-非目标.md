  （「仅注入渲染层」原为非目标，2026-09-25 翻案，理由见 3.22 与 [附录 A](./A-方向审查与否决理由.md) §8.5。）

- **跨文件聚合视图**（总索引、跨笔记聚合目录）：走 Roadmap M9「Dataview 集成」路线。单文件内的目录
  不在此列——0.7.28 翻案为 TOC burn-in（[3.16](./3.16-原生风格TOC-burn-in.md)），理由是 burn-in 真实文本别的插件做不到。

- Git 感知最小化差异（后续版本）
- 标题居中 / 自定义字体等**渲染层美化**（与「burn-in 写入」哲学冲突，明确不做；有此需求可用 Auto Heading）

> **1.3.1** is a bug-fix release: headings that start with an English word are no longer mistaken for hand-written numbering, headings that already are a number (like "Chapter One" in Chinese) are no longer numbered twice, and a new install no longer switches itself from "Display only" to writing numbers after a restart.
>
> **1.3.1** 是一个修复版本：英文词开头的标题不再被当成手写编号；本身就是编号的标题（如「第一章」）不再叠编号；新装后重启一次，不会再从「仅显示」自己切成往文件里写编号。

## What's new / 更新内容

**English**

**Headings that start with an English word**

- Headings like `## git basics`, `## GPG signing`, `## API design`, `## vim config`, `## XML parsing`, `## CLI tools` or `## C language` are now treated as normal text. Before, the plugin could take the first word for a letter or Roman numeral: it skipped numbering the whole note and asked you to clean up "numbering not added by this plugin", and the cleanup could delete that word.
- Real hand-written numbering is still recognized: `1.`, `1.1`, `a)`, `A.`, `(a)`, `iv.`, `IV、`. A letter or Roman numeral followed only by a space (`IV Conclusion`) no longer counts as numbering.
- Thanks to **@smallerxie** for reporting this and contributing the fix (#11).

**Headings that already are a number**

- Notes whose headings are only a number, like `# 第一章` / `## 第一节` (Chapter One / Section One in Chinese), are no longer numbered a second time ("第一章 第一章"). The plugin leaves them as they are and tells you why.

**New installs stay "Display only"**

- A new install starts in "Display only" mode, which shows numbers without changing your files. Before, restarting Obsidian once without having changed any setting switched it to writing numbers into your notes. Fixed on all platforms, including when the vault syncs to a second device.
- If you installed between 1.2.0 and 1.3.0 and the plugin started writing numbers on its own, open Settings → Auto Headings and set the root path rule `/` back to "Display only".

**中文**

**英文词开头的标题**

- `## git 相关`、`## GPG 签名策略`、`## API 设计`、`## vim 配置`、`## XML 解析`、`## CLI 工具`、`## C 语言` 这类标题，现在按正文处理。以前插件可能把第一个词当成字母或罗马数字序号：整篇不自动编号，还提示你去清理「非本插件的标题编号」，清理时会把这个词删掉。
- 真正的手写编号照旧能识别：`1.`、`1.1`、`a)`、`A.`、`(a)`、`iv.`、`IV、`。字母或罗马数字后面只跟空格的写法（`IV 结论`）不再算编号。
- 感谢 **@smallerxie** 报告问题并贡献修复（#11）。

**本身就是编号的标题**

- 标题只有编号的笔记（如 `# 第一章` / `## 第一节`）不会再被叠成「第一章 第一章」。插件会保持原样，并提示原因。

**新装保持「仅显示」**

- 新装默认是「仅显示」模式：只显示编号，不改文件。以前装好后没改任何设置、重启一次 Obsidian，就会切成往笔记里写编号。现已修复，所有平台都适用，库同步到第二台设备也一样。
- 如果你是在 1.2.0–1.3.0 之间新装的，并且发现插件自己开始往文件里写编号：打开「设置 → Auto Headings」，把根路径规则 `/` 改回「仅显示」即可。

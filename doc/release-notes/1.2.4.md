> **1.2.4** makes heading link suggestions much quieter: they now pop up only when what you typed really points at a heading, and work more smoothly alongside Various Complements. Thanks to the report in [issue #10](https://github.com/AArlert/obsidian-auto-headings/issues/10).
>
> **1.2.4** 让标题链接建议安静了很多：只在你打的字确实指向某个标题时才弹出，和 Various Complements 一起用也更顺。感谢 [issue #10](https://github.com/AArlert/obsidian-auto-headings/issues/10) 的反馈。

## What's new / 更新内容

**English**

**Heading link suggestions pop up less, and when they should**

- **Triggered by signals, not length.** From 6 letters (or 3 CJK characters) on, headings starting with what you typed are suggested. Shorter words must exactly match a heading: Latin terms like `uart` or `axi` pop up right away; two-character CJK words also need the heading to be linked somewhere in your vault. In a run of text with no space or punctuation, only a complete heading counts.
- **Template sections are left out.** A heading that appears in 3 or more notes (a "Summary" in every note, say) no longer shows up, and neither do headings inside Excalidraw drawings.
- **Better ranking.** Exact matches first, then headings linked more often, then headings in the current note.
- **Suggestions inside heading lines.** You can now link to another heading while writing a heading; only the heading you're writing is left out.
- **Same-named notes link correctly.** When several notes share a file name, the inserted link uses the path, so it opens the note you picked.
- Pressing Tab while an input method is composing no longer accepts a suggestion.

**With Various Complements (VC)**

- **One setting: "Show suggestions in".** Choose this plugin's popup or VC's popup; it replaces the two earlier VC dropdowns. Existing setups map onto it automatically: dictionary integration on means VC's popup, off means this plugin's popup.
- **This plugin's popup really comes first** when you choose it, no matter which plugin loaded first, and it takes over again after you commit text with an input method.
- **VC's popup stays current.** New headings show up in VC within about half a second without restarting, renamed or deleted headings disappear right away, and the heading you're writing is never offered to itself.
- **Leaving VC's popup cleans up.** Switching back asks whether to remove this plugin's dictionary from VC; a leftover dictionary is flagged in settings with a one-click remove. Changes to VC take effect immediately.
- Auto setup now sets VC's custom-dictionary trigger to 2 characters (only raised, never lowered).

**Fixes**

- The debounce slider no longer shows its value twice on Obsidian 1.14.
- After creating a new heading, the cursor lands after the number instead of before it.

**中文**

**标题链接建议：少弹，该弹时才弹**

- **按信号触发，不再只看长度。** 打到 6 个字母（或 3 个汉字）起，以它开头的标题会出现在建议里；更短的词要**完整等于**某个标题：`uart`、`axi` 这类英文术语直接弹出，两个汉字的词还要求这个标题在库里被链接过。没有空格或标点的连写中间，只认完整的标题。
- **模板小节不参与。** 同名出现在 3 篇及以上笔记里的标题（比如每篇都有的「总结」）不再出现，Excalidraw 绘图里的标题也不进。
- **排序更合理。** 完整命中的在前，然后是被链接次数多的，再是当前笔记里的。
- **标题行里也能用。** 写标题时也可以链到别的标题，只排除正在写的这一条。
- **同名笔记链对了。** 多篇笔记文件名相同时，插入的链接带上路径，点开就是你选的那篇。
- 输入法拼字时按 Tab 不再误选建议。

**与 Various Complements（VC）一起用**

- **只剩一个「建议显示在」。** 选本插件的建议框或 VC 的建议框，取代原来的两个 VC 下拉。升级后自动对应：原来开着词典联动的算「VC 的建议框」，没开的算「本插件的建议框」。
- **选「本插件的建议框」就真的是本插件优先**，不受插件加载顺序影响；用输入法上屏后也会接回本插件的框。
- **VC 的框跟得上。** 新写的标题约半秒后就能在 VC 框里打出来，不用重启；改名或删掉的标题立刻不再出现；正在写的标题不会把自己列成候选。
- **切回时帮你收尾。** 从 VC 的框切回时会问要不要把本插件的词典从 VC 移除；残留的词典会在设置里提示，并附一键移除。改 VC 的设置立即生效。
- 自动配置把 VC 自定义词典的触发字数设为 2（只抬高、不调低）。

**修复**

- 防抖滑块在 Obsidian 1.14 上不再并排显示两个数值。
- 新建标题后，光标落在编号之后而不是之前。

> **1.2.6** makes the heading menu easier to use: set a heading's level (or a whole section's) straight from a submenu, and use the menu in reading view for real.
>
> **1.2.6** 改进标题菜单：直接在子菜单里选标题（或整节）的层级，阅读视图里的菜单项也真正生效了。

## What's new / 更新内容

**English**

**Heading menu**

- **"Set this heading's level" and "Set section level (with subheadings)".** Right-click the fold arrow beside a heading and pick H1–H6 from the submenu. The first changes only that heading; the second moves the whole section, subheadings included. The current level is ticked, and levels that would push any subheading past H1–H6 are greyed out, so the section's structure is never flattened. To go back, just pick the old level again.
- **Works in reading view.** Skip, level changes and the other items now really edit the file when you use the menu in reading view (before, they did nothing there except copy link / embed). These edits can't be undone with the editor's undo.
- **"Back" lines up.** From the heading menu, "Numbering settings for this note…" opens the note menu with its "Back" item at the bottom, aligned to the corner of the menu you came from.

**Settings**

- New **Menus** group in Settings → General: turn the **heading menu** and the **status bar menu** on or off. Both are on by default.

**Commands**

- Added "Promote / Demote current heading (without subheadings)"; the existing promote / demote section commands are unchanged.

**中文**

**标题菜单**

- **「调整此标题的层级」和「调整整节的层级（含子标题）」。** 右键标题左侧的折叠箭头，在右侧子菜单里直接选 H1–H6：前者只改这一个标题，后者连同子标题整节一起移动。当前层级打勾；会让任何子标题越出 H1–H6 的层级置灰不可选，所以整节的结构不会被压扁，要回去直接选回原层级即可。
- **阅读视图里真正生效。** 在阅读视图里用菜单，跳过、调整层级等项现在真的会改文件（以前除复制链接 / 嵌入外都没反应）。这类改动无法用编辑器的撤销还原。
- **「返回」对得上了。** 从标题菜单点「本篇编号设置…」打开的本篇菜单，「返回」在最下面，并与来时的菜单左下角对齐。

**设置**

- 设置 → 全局设置新增「菜单」分组：可分别开关**标题菜单**和**状态栏菜单**，默认都开。

**命令**

- 新增「升级 / 降级当前标题（不含子标题）」；原有的升级 / 降级当前小节命令不变。

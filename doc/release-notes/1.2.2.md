> **1.2.2** is a visual refresh of the settings panel — numbering itself works exactly as before — plus fixes for links inside note properties.
>
> **1.2.2** 是设置面板的视觉更新——编号本身的行为不变——另外修复了笔记属性里的链接同步。

## What's new / 更新内容

**English**

**Settings, redesigned**

- **Closer to Obsidian's own settings.** Section headings and dialog titles now use Obsidian's native styles, descriptions fit on one line (the longer explanations moved into the user guide), and the tabs have four short names: *General*, *Paths & templates*, *Maintenance* (formerly *Sensitive actions*) and *About*.
- **Path rules.** The row-number column is gone; instead, a small dot marks the rule your current note uses. *Add rule* sits next to the section title. On phones, each rule takes two rows, with *Batch renumber* and *Delete* in a ⋯ menu.
- **Templates as cards.** Each template is a card that previews H1–H6 at a glance, shows how many rules use it and its whitelist size, and has *Edit*; *Delete* lives in the ⋯ menu (the built-in default template can't be deleted).
- **New template editor.** *Edit* opens a wide dialog with a *Format* tab and a *Whitelist* tab. Changes still apply immediately.
  - The range and the extra rules are two lines above the format table. *Inherit parent* and *Inherit depth* are merged into one *Parents* column (None / All / 1 level / …). Spaces show as ␣ when a field isn't focused.
  - A live preview at the bottom renders your current note (or a sample) with the template you're editing, labels each heading H1–H6, and highlights a level when you hover its row.
  - The footer tells you how many rules and notes the template affects.
  - The whitelist tab explains the `=` / `≈` / `▸` symbols in one line and hides zero-hit badges.
- **Maintenance tab.** It is split into *Current note* (renumber now, clear numbering, clean up non-plugin numbering, clear leftover numbering) and *Whole vault* (clear vault numbering, freeze numbering). *Clean up non-plugin numbering* now shows the review dialog first. The two whole-vault actions ask you to type a confirmation word ("clear" / "freeze") before the red button unlocks.
- **Non-plugin numbering review.** The dialog gains a *Select all* checkbox with a "selected / total" count, unchecked items fade out, and the confirm button says how many headings it will change. The prompt that opens it now states how many headings look hand-numbered.
- **About.** The description follows your interface language, and the repository and issue links are now buttons.
- **The debounce slider shows its value.** Settings for Various Complements only appear while that plugin is enabled, or while the dictionary integration is on.
- **Numbers in the Outline pane are always on.** The *Show numbers in the outline* toggle has been removed.

**Fixes**

- **Links in note properties.** Heading links inside properties (e.g. `related: "[[Note#Heading]]"`) are rewritten respecting YAML quoting, so renaming a heading can no longer break a note's properties. Notes that reference a heading *only* from their properties are now found, too.
- Setting descriptions no longer show literal `**` asterisks.

**中文**

**设置面板重新设计**

- **更贴近 Obsidian 自带的设置页。** 分区标题和弹窗标题改用原生样式；说明一律一行，长解释移进使用指南；TAB 名一律四个字：全局设置 / 路径模板 / 编号维护（原「敏感操作」）/ 关于插件。
- **路径规则。** 去掉了行号列，改为在当前笔记所用的那条规则前显示一个小圆点；「添加规则」挪到标题行右侧。手机上每条规则分两行显示，「批量重编号」和「删除」收进 ⋯ 菜单。
- **模板改成卡片。** 每张卡片预览 H1–H6 的编号样式，写明被几条规则使用、白名单几项，并有「编辑」按钮；「删除」在 ⋯ 菜单里（内置的默认模板不能删）。
- **全新的模板编辑弹窗。** 点「编辑」打开宽弹窗，分「格式」「白名单」两页，改动依旧即时生效。
  - 格式页上方两行是编号范围和更多规则。「继承前级」和「继承级数」合成一列「上级编号」（不带 / 全部 / 1 级 / …）。输入框没聚焦时，空格显示为 ␣。
  - 底部预览用正在编辑的模板渲染当前笔记（或示例），每行标出 H 几；鼠标停在某一行时，同级标题高亮。
  - 弹窗底部写明这个模板影响多少规则、多少篇笔记。
  - 白名单页顶部用一行说明 `=` / `≈` / `▸` 三个符号，命中 0 次的条目不再显示角标。
- **编号维护。** 分「当前笔记」（立即重新编号、清除当前文件编号、清理非本插件编号、清除残留编号）和「整个仓库」（清除全库编号、固化编号）两组。「清理非本插件编号」现在会先弹出逐条确认的预览框。全库两项须先输入确认词（「清除」/「固化」），红色确认按钮才能点。
- **外来编号清理弹窗。** 新增「全选」勾选框，并显示「已选 X / N」；取消勾选的条目会变淡；确认按钮写明要清理几处。打开它的提示也会说明有几处标题像是手写编号。
- **关于插件。** 简介跟随界面语言，仓库和反馈链接改成按钮。
- **防抖滑块旁直接显示当前数值。** Various Complements 相关设置只在该插件启用、或词典联动已开启时才显示。
- **大纲面板的编号固定开启。** 删除了「在大纲中显示编号」开关。

**修复**

- **属性里的链接。** 属性里的标题链接（如 `related: "[[笔记#标题]]"`）改名时按 YAML 的引号规则改写，不会再把笔记属性写坏；只在属性里引用某标题的笔记，现在也能被找到并同步。
- 设置说明里不再露出 `**` 星号。

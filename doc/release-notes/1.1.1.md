## Concise settings copy, bilingual / 设置面板与弹窗文案全面瘦身（中英双语）

**English**

This release is about the settings screen, not the engine: every long description, dialog and notice has been rewritten to be short enough to read at a glance — one key sentence up front, warnings and defaults kept, filler gone.

- All settings descriptions, section intros, confirmation dialogs, and notices are now concise in both English and 中文.
- Nothing behavioral changed: the same features, defaults and boundaries; only the words got leaner.

**中文**

这个版本不动引擎，只瘦身设置界面：所有长说明、确认框与提示都重写为「一眼看清关键句」的精要版——关键句在前，警告与默认值保留，废话删光。

- 设置项说明、分区导语、确认框、Notice 全部压缩，中英双语同步。
- 行为零改动：功能、默认值、边界都不变，只是文字变精炼了。

## Heading link suggestions, and a bridge to Various Complements / 标题链接建议，以及与 Various Complements 的联动

**English**

This release adds the second half of what this plugin is for. Numbering your headings is only useful if you can then *point* at them — so now you can.

**Heading link suggestions (on by default, no other plugin required).** As you type in any note, text that matches a heading anywhere in your vault brings up a suggestion. Accept it and your text is replaced with a working link to that heading, expanded to the heading's full name. Numbered headings work correctly: the anchor is built from the real heading text, so links survive renumbering. The index is built once after startup and maintained incrementally; turning the feature off builds nothing at all.

Chinese and other scripts without spaces get special handling. Typing `一个交叉矩阵` in one breath still surfaces the heading `交叉矩阵` — the trigger word falls back through progressively shorter suffixes until one matches, and only the part that actually matched gets replaced, so the `一个` you already typed stays put.

**Various Complements integration (off by default, always asks first).** If you use Various Complements, Obsidian will only ever show one suggestion popup at a time — the two plugins compete for the same slot. Rather than one silently hiding the other, this plugin can export its heading index as a VC custom dictionary, so heading candidates appear *inside* VC's popup alongside VC's own suggestions. Two modes: **manual** (generates the dictionary file and shows you the path to paste in — touches none of VC's settings) and **automatic** (also configures VC for you, listing every setting it will write before it does anything). Layered safety throughout: if anything about VC's config looks unfamiliar, the whole write is abandoned rather than half-applied.

A setting controls what happens when VC is enabled: yield to VC (the default, but only while the dictionary integration is actually on — otherwise you'd be left with no heading suggestions at all), or let this plugin's own popup win.

**中文**

这个版本补上了本插件的另一半。给标题编号，只有在你能**指向**它们的时候才真正有用——现在可以了。

**标题链接建议（默认开启，不依赖任何其它插件）**：在正文里打字，只要文字与库内某个标题匹配就会弹出建议；接受后替换为指向该标题的可用链接，并自动补全为标题的完整名称。已编号的标题也正确工作——锚点取自真实标题文本，重新编号不会让链接失效。索引在启动后构建一次、随后增量维护；关掉这个功能则完全不构建。

中文这类没有空格的书写系统做了专门处理：一口气打出「一个交叉矩阵」，标题【交叉矩阵】照样出现在候选里——触发词会逐级回退到更短的后缀直到匹配上，而且**只替换真正匹配上的那一段**，你已经打好的「一个」原样保留。

**Various Complements 联动（默认关闭，开启前必须确认）**：如果你在用 Various Complements，Obsidian 同一时刻只会显示一个建议框——两个插件抢的是同一个位置。与其让其中一个悄悄盖住另一个，本插件可以把标题索引导出为 VC 的自定义词典，让标题候选出现在 **VC 的建议框里**，与 VC 自己的候选并排显示。两种模式：**手动**（生成词典文件并显示路径供你粘贴，不碰 VC 的任何配置）与**自动**（额外替你配置 VC，动手前会逐条列出要写入什么）。全程分层防御：只要 VC 的配置形状有任何不认识的地方，整个写入就放弃，绝不做一半。

另有一项设置决定 VC 启用时谁优先：让路给 VC（默认，但仅在词典联动确实开着时才生效——否则你会一条标题建议都看不到），或者本插件优先。

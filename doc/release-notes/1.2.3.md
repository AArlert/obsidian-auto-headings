> **1.2.3** brings numbering controls into the note itself: a menu on each heading's fold arrow, drag-to-move sections, and per-note templates and auto-numbering.
>
> **1.2.3** 把编号操作搬进了笔记里：标题折叠箭头上的菜单、拖动整节、单篇笔记的模板与自动编号开关。

## What's new / 更新内容

**English**

**Work right in the note**

- **Heading menu.** Right-click the fold arrow beside a heading for: skip numbering for this heading, skip the whole section (sub-headings included), promote / demote the section, copy a section link, copy a section embed (`![[Note#Heading]]`), and this note's numbering settings. On phones, a ⋯ button appears at the end of the heading line you're on.
- **Drag to move a section.** Drag a heading's fold arrow to move the section with all its sub-headings; a line shows where it will land. A plain click still folds / unfolds.
- **"This note" in the status bar.** Shows which path rule the note matches, and lets you set auto-numbering for just this note (follow global / always / never), pick a different template for it, renumber, copy the numbered outline, or clear leftover numbering.
- **Two skip markers.** `<!-- skip -->` skips a single heading; the new `<!-- skip-tree -->` skips a heading and everything under it.
- **New commands.** Skip / restore numbering for the heading or the whole section at the cursor, copy the current section's embed link, promote / demote the current section, choose a template for the current note, toggle auto-numbering for the current note. Existing commands were renamed to a consistent "verb + object" style (their IDs are unchanged, so hotkeys keep working).
- **Link aliases follow renamed headings.** When a heading is renamed, a link's `|alias` that matched the old heading text is updated too.

**Templates and settings**

- **Quick apply and history in the template editor.** A *Quick apply* menu on the Format tab offers your four most recent styles plus a few presets; a *History* dialog lists earlier versions. A history entry is saved when you close the editor after changing the style.
- **"Don't number" moved to the *Mode* dropdown** of a path rule.
- **Clearing the whole vault** can now also turn off auto-numbering in the same step (checkbox in the confirmation dialog).
- The template editor has a solid background, and the "current note" dot sits before the drag handle in path rules.

**Under the hood**

- Uses Obsidian's own DOM helpers and the newer destructive-button style where available; the copy-path button no longer relies on the deprecated `execCommand`.
- The README FAQ now explains what the plugin accesses (vault files, clipboard) and why.

**中文**

**在笔记里就能操作**

- **标题菜单。** 右键标题旁的折叠箭头：跳过此标题的编号、跳过整节的编号（含子标题）、升级 / 降级本节、复制本节链接、复制本节嵌入（`![[笔记#标题]]`），以及本篇编号设置。手机上，光标所在的标题行末会出现一个 ⋯ 按钮。
- **拖动整节。** 按住折叠箭头拖动，可以把整节（含所有子标题）挪到别处，横线标出落点；单击照旧是折叠 / 展开。
- **状态栏「本篇」菜单。** 显示这篇笔记命中的路径规则，可以单独设置这篇的自动编号（跟随全局 / 始终编号 / 不编号）、换个模板、立即重新编号、复制编号大纲、清除残留编号。
- **两种跳过标记。** `<!-- skip -->` 只跳过这一个标题；新增的 `<!-- skip-tree -->` 跳过这个标题和它下面的所有子标题。
- **新命令。** 跳过 / 恢复光标所在标题或整节的编号、复制当前小节的嵌入链接、升级 / 降级当前小节、为当前笔记选择模板、切换当前笔记的自动编号。已有命令统一改为「动词 + 对象」的名字（命令 ID 不变，快捷键照常可用）。
- **链接别名跟着标题改名。** 标题改名时，链接里与旧标题相同的 `|别名` 也一起更新。

**模板与设置**

- **模板编辑弹窗加「快速套用」和「历史」。** 格式页的「快速套用」菜单列出最近 4 份样式和几个预设；「历史」弹窗列出更早的版本。改过样式后关闭编辑弹窗，会自动记一份历史。
- **路径规则的「不编号」挪到了「模式」下拉里。**
- **清除全库编号**的确认框里可以勾选「同时关闭自动编号」，一步完成。
- 模板编辑弹窗改为实色背景；路径规则里「当前笔记」的小圆点挪到拖拽手柄之前。

**其他**

- 改用 Obsidian 自带的 DOM 助手，按钮在新版 Obsidian 上使用新的「破坏性操作」样式；「复制路径」不再依赖已废弃的 `execCommand`。
- README 常见问题里说明了插件会访问哪些内容（库文件、剪贴板）以及用途。

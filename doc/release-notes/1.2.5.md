> **1.2.5** turns heading link suggestions off by default, so typing behaves exactly like plain Obsidian unless you turn them on. Thanks to the report in [issue #10](https://github.com/AArlert/obsidian-auto-headings/issues/10).
>
> **1.2.5** 把「打字时建议标题链接」改为默认关闭：不打开它，打字就和原生 Obsidian 完全一样。感谢 [issue #10](https://github.com/AArlert/obsidian-auto-headings/issues/10) 的反馈。

## What's new / 更新内容

**English**

**Heading link suggestions: off unless you want them**

- **Off by default.** The setting is now called "Suggest heading links as you type" (Settings → General). New installs start with it off.
- **Upgrading turns it off once.** Every vault is switched off when you update to 1.2.5, because until now the setting was on by default and there's no telling whether you chose it. If you use it, turn it back on in settings; it will stay on from then on. Vaults with the Various Complements dictionary integration turned on keep their setting, since that was an explicit choice.
- **Enter never picks a suggestion.** With suggestions on, Enter starts a new line as usual (lists continue to the next item) and closes the popup. Only Tab or a click inserts the link.
- **Fewer, better-aimed suggestions when it's on.** Short words now pop up only for headings relevant to what you're writing (linked at least twice, in the current note or its folder, or already linked from this note), and English words need 8 letters before prefix matching starts. In a replay of a real 300-note vault this cut popups by about a third.
- **Not picked means not again.** If a suggestion pops up and you don't pick it (Esc, Enter, or keep typing), that word won't pop up again in this note until you switch away.
- While it's off, Obsidian's own `[[##` still links to any heading in your vault.

**This note menu and heading menu**

- **Single-note actions moved to the status-bar "this note" menu.** Renumber now, clean up hand-typed numbering, and (for display-only notes) clear leftover numbers are there; the Numbering maintenance tab keeps only the vault-wide actions.
- **"Don't number this note" also removes this plugin's numbers** (hand-typed numbers stay). Undo once to get the numbers back while keeping the note un-numbered.
- **The heading menu works in reading view too:** right-click the fold arrow beside a heading. Dragging sections stays in the editing view.

**More**

- Interface now also in 繁體中文, 日本語, Español, Français, Deutsch, Русский, 한국어 and Português (Brasil). Corrections from native speakers are welcome.
- New path rules default to "Display only".

**Fixes**

- In Live Preview, "Renumber now" on a paused note really renumbers and resumes it (before, it said so but changed nothing).
- Changing a note from the reading-view menu while the same note has unsaved edits in another pane no longer loses either change.

**中文**

**标题链接建议：想用才开**

- **默认关闭。** 设置项改名为「打字时建议标题链接」（设置 → 全局设置），新装默认关。
- **升级时统一关一次。** 以前这一项默认是开的，分不清是默认还是你自己打开的，所以升级到 1.2.5 时一律先关掉；在用的话去设置里再打开，之后就一直保持开着。开着 Various Complements 词典联动的库保持原样——那是你明确选的。
- **回车不再选中建议。** 打开建议后，回车照常换行（列表里照常续出下一项）并关掉建议框，只有 Tab 或点按才插入链接。
- **开着时弹得更少、更准。** 短词只在标题和你正在写的东西有关时才弹（被链接过至少 2 次、就在当前笔记或同一文件夹里，或当前笔记链过它）；英文要打到 8 个字母才开始按前缀匹配。用一个约 300 篇笔记的真实库重放，弹框少了约三分之一。
- **没选就不再弹。** 建议弹出来你没选（按 Esc、回车或接着打字），这个词在这一篇里就不再弹，切到别的笔记后重新算。
- 关着的时候，用 Obsidian 自带的 `[[##` 照样能链接到库里任意标题。

**「本篇」菜单与标题菜单**

- **单篇操作搬进状态栏的「本篇」菜单**：立即重新编号、清理手写编号、（仅显示笔记）清除残留编号都在这里；「编号维护」页只留全库操作。
- **「这篇不编号」顺手清掉本插件写的编号**（手写的不动）；想留编号文字的话撤销一次即可，笔记仍保持不编号。
- **阅读视图里也能用标题菜单**：右键标题旁的折叠箭头。整节拖动仍只在编辑视图里做。

**其他**

- 界面新增繁體中文、日本語、Español、Français、Deutsch、Русский、한국어、Português (Brasil)，欢迎母语用户指正。
- 新增路径规则默认「仅显示」。

**修复**

- 实时预览下，对暂停编号的笔记点「立即重新编号」现在会真的重新编号并恢复（之前提示成功却什么都没变）。
- 同一篇笔记在另一个窗格里有未保存的编辑时，在阅读视图里用菜单改它，两边的改动都不会丢。
